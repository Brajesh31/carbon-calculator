# 📖 Glossary

| Term | Meaning in this project |
|---|---|
| Activity data | A measured or estimated quantity such as kilometres travelled or kWh consumed |
| Annualization | Converting daily, monthly, or weekly quantities to an annual quantity |
| Carbon footprint | A defined inventory of greenhouse-gas emissions attributable to an entity or activity |
| CO₂ | Carbon dioxide |
| CO₂e | Carbon dioxide equivalent, a common unit that expresses different greenhouse gases using a stated warming-potential basis |
| Emission factor | Emissions per unit of activity, such as kg CO₂ per kWh |
| Geography | Region to which a factor or dataset applies |
| System boundary | Activities and lifecycle stages included in a calculation |
| Data vintage | Publication or reporting period represented by a factor |
| Uncertainty | Range or quality limitation associated with a factor or activity estimate |
| Provenance | Traceable origin and metadata for a dataset or factor |

The current app labels its outputs CO₂. Do not use CO₂e interchangeably unless the calculation is updated to support that basis.
