# Changelog

This file records notable changes to Personal Carbon Calculator. The repository
does not currently use tagged releases or a formal versioning scheme, so entries
are grouped by date or under `Unreleased` until releases are established.

## Unreleased

### Project baseline

- The application is a single-file Streamlit prototype in `app.py`.
- It estimates annual emissions for transportation, electricity, diet, and
  waste from fixed factors marked in the source as examples.
- India is the only selectable country. The factors, their source data, and the
  displayed national comparison do not have documented citations or a complete
  calculation methodology in the application baseline.
- There is no declared dependency manifest, automated test suite, persistent
  database, or external application API in the baseline.

These notes describe the repository as inspected when documentation was
prepared. They are not a claim that the estimates have been validated.
