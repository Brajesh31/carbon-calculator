# Support

This project is a small educational Streamlit prototype. Support is provided
through the public GitHub repository and is best effort; no response time or
service availability is guaranteed.

## Get help with the app

1. Check [README.md](README.md) for prerequisites and local startup steps.
2. Check [docs/faq.md](docs/faq.md) and
   [docs/troubleshooting.md](docs/troubleshooting.md) for common questions.
3. Search existing GitHub issues before opening a new one.
4. If the problem remains, open an issue at
   <https://github.com/Brajesh31/carbon-calculator/issues>.

Include the operating system, Python and Streamlit versions, the command used,
the behavior you expected, and the behavior you observed. For calculation
issues, include reproducible example inputs and the expected result with the
calculation shown. Remove private information, tokens, and local paths from
logs before posting.

## Suggest improvements

Use a GitHub issue to discuss new categories, country support, factor sources,
accessibility, or deployment changes. For changes to emissions factors, include
the source, geographic coverage, date or reporting period, units, system
boundary, and conversion assumptions. See [CONTRIBUTING.md](CONTRIBUTING.md)
for the contribution process.

## Report a security issue

Do not post vulnerabilities, credentials, or sensitive deployment details in a
public issue. Follow the private reporting instructions in
[SECURITY.md](SECURITY.md).

## Project limitations

The current factors and the comparison statistic shown by the app are not
adequately sourced or validated. Support requests cannot certify results for
scientific, financial, regulatory, or other consequential use. See
[docs/architecture.md](docs/architecture.md) for the implemented scope and
[docs/faq.md](docs/faq.md) for interpretation guidance.
