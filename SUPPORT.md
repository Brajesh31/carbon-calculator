# 🆘 Support

This project is an educational Streamlit prototype. Support is best effort; no response time, uptime, or service availability is guaranteed.

## Find an answer

1. Start with [README.md](README.md).
2. Read [docs/README.md](docs/README.md) for the documentation index.
3. Check [docs/faq.md](docs/faq.md).
4. Check [docs/troubleshooting.md](docs/troubleshooting.md).
5. Search existing GitHub issues.
6. Open a new issue if the problem is reproducible and not already reported.

## What to include in a support issue

- Operating system and version.
- Python and Streamlit versions.
- Command used to start the app.
- Expected behavior and observed behavior.
- Reproduction steps.
- Sanitized traceback or logs.
- Example inputs that contain no personal or sensitive information.

## Suggest an improvement

Use the feature-request template. For a new factor or formula, include original source, date, geography, units, boundary, gas basis, conversion assumptions, uncertainty, and license.

## Security reports

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

## Important limitations

The current factors and national comparison are not adequately sourced or validated. Support cannot certify the results for scientific, financial, regulatory, or other consequential use. See [docs/methodology.md](docs/methodology.md).
